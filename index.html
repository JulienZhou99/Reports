一眼看懂：产业链的三条主线

制冷剂看起来品种很多，但源头其实高度集中：一条是“萤石 → AHF → 含氟有机物”，一条是“氯碱/石化 → 氯代烃中间体”，第三条是“天然工质/液冷介质”。

上游资源：萤石、硫酸、盐、天然气/乙烯/乙炔 中间体：AHF、氯仿、二氯甲烷、TCE/PCE、VDC 三代HFC：R32、R125、R134a、R143a、R152a 四代HFO/HCFO：R1234yf、R1234ze、R1233zd 约束变量：配额、GWP、原料、装置安全、客户认证

① 资源与基础化工

萤石 CaF2酸级萤石粉是含氟制冷剂的核心资源；价格影响AHF和HFC/HFO成本。矿山浮选烘干
硫酸 H2SO4与萤石反应生成氟化氢；副产石膏/含氟尾气需处理。硫磺/冶炼酸储罐
盐/氯碱盐水电解提供氯气、烧碱、氢气，是氯代烃和氟化工副产HCl消纳的基础。离子膜电解槽氯气压缩
天然气/甲醇/乙烯/乙炔提供C1、C2、C3碳骨架，进入甲烷氯化物、氯代乙烯、丙烯氯化中间体。石化煤化工

② 关键中间体

无水氟化氢 AHF萤石 + 硫酸，经反应、冷凝、精馏、吸收/尾气处理得到；是绝大多数含氟制冷剂的“氟源”。预反应器回转窑精馏塔洗涤塔
↓ 与氯代烃发生卤素交换/氟化
甲烷氯化物二氯甲烷、氯仿等；分别进入R32、R22等路线。氯化反应器分离塔
氯代乙烯/乙烷TCE、PCE、VDC、1,1,1-三氯乙烷等；进入R125、R134a、R143a、R152a、PVDF相关路线。氯化氧氯化裂解/分离
C3氯代中间体HCC-240、四氯丙烯、HCFO-1233xf、HFC-245fa等；进入HFO-1234yf/ze、HCFO-1233zd。氯化异构化脱卤化氢

③ 单质与混配制冷剂

二代 HCFCR22等：曾是空调/冷冻主力，也用于PTFE等含氟材料中间体；受ODS配额持续约束。R22HCFC-142bHCFC-141b
三代 HFCR32、R125、R134a、R143a、R152a：不破坏臭氧层，但GWP较高，2024年起中国正式实施HFC配额管理。配额品价格弹性
混配制冷剂R410A、R407C、R404A、R507A等由单质HFC按标准比例混配；新一代R454B/R513A等引入HFO降低GWP。混配釜在线称重GC检测
四代 HFO/HCFOR1234yf、R1234ze、R1233zd：低GWP，汽车空调、冷水机、发泡剂/溶剂等替代方向明确，壁垒在技术、成本和客户认证。低GWP专利/工艺
天然工质R290、R600a、R717、R744：低GWP，但存在可燃性、毒性或高压系统设计要求。丙烷异丁烷氨CO2
数据中心液冷介质水/乙二醇、丙二醇、去离子水、合成烃/硅油/氟化液等；不完全等同于传统制冷剂。CDU冷板浸没液

④ 终端应用

家用/商用空调R32、R410A存量、低GWP混配、R290探索。
汽车空调R134a存量，R1234yf新增替代。
冷链/商超/工业制冷R404A/R507A存量，CO2、NH3、R448A/R449A替代。
冷水机/热泵R134a、R513A、R1234ze、R1233zd、R32、R290。
算力/数据中心冷站用制冷剂 + 机柜侧液冷介质；高密度AI机柜更偏液冷而非直膨HFC。

产品路线卡：原料 → 中间品 → 产成品 → 设备

以下路线是产业研究层级的“主流路径/典型路径”，不同企业会因专利、装置、循环副产物处理不同而存在差异。

AHF 无水氟化氢

氟源
原材料酸级萤石粉、硫酸，辅以水、电、燃料/蒸汽。
核心流程萤石预处理 → 与硫酸反应 → HF气体冷凝/净化 → 精馏/吸收 → AHF储运。
副产/处理硫酸钙、含氟硅化物、酸性尾气；需要洗涤、中和和固废处理。
关键设备萤石干燥系统、预反应器、回转窑、冷凝器、精馏塔、吸收塔、尾气洗涤塔、耐HF储罐。

R22 / HCFC-22

二代
原材料氯仿、AHF；上游对应甲烷氯化物和萤石-AHF。
典型路径氯仿氟化 → 粗R22/HCl/轻重组分 → 酸气分离 → 精馏提纯 → 充装。
中间/副产可能产生含氟副产物，包括需严格控制的HFC-23副产物。
关键设备氟化反应器、HCl吸收系统、压缩冷凝、精馏塔组、尾气焚烧/分解或回收系统。

R32 / HFC-32

家空主力
原材料二氯甲烷、AHF；成本看氯碱、甲烷氯化物、萤石/AHF。
典型路径二氯甲烷氟化 → 粗R32 → 除酸/干燥 → 精馏 → 高纯R32。
产品去向单质R32用于家用空调、热泵；也用于R410A、R454B等混配。
关键设备氟化反应器、HCl吸收塔、分子筛干燥器、精馏塔、低温储罐、气相色谱质检。

R125 / HFC-125

混配核心
原材料PCE/TCE等氯代乙烯中间体、AHF。
典型路径氯代乙烯多步氟化 → HCFC/HFC中间体 → R125粗品 → 精馏提纯。
产品去向R410A、R404A、R507A、R407C等混配制冷剂的重要组分。
关键设备多级氟化反应器、循环压缩、酸气吸收、精馏塔、重组分处理、混配系统。

R134a / HFC-134a

汽车/冷水机存量
原材料TCE等C2氯代烃、AHF。
典型路径TCE氟化 → HCFC-133a等中间体 → 进一步氟化/转化 → R134a → 精馏。
产品去向汽车空调存量维修、冷水机、气雾剂、部分混配制冷剂。
关键设备氟化反应器、相分离/除酸、精馏塔组、干燥器、成品罐、钢瓶/槽车充装线。

R143a / HFC-143a

低温混配
原材料VDC或相关氯代乙烷/乙烯中间体、AHF。
典型路径VDC氟化 → HCFC-142b等中间体/伴生组分 → R143a → 分离提纯。
产品去向R404A、R507A等中低温制冷剂组分。
关键设备连续氟化反应器、冷凝分离、酸气吸收、精馏系统、防爆储运与充装。

R152a / HFC-152a

低GWP HFC
原材料乙炔或氯乙烯/VDC路径、AHF。
典型路径乙炔加氟或氯代乙烯氟化 → 粗R152a → 除酸/干燥 → 精馏。
产品去向气雾剂、发泡剂、混配制冷剂；因可燃性，制冷端应用需系统适配。
关键设备反应器、冷凝器、分离塔、防爆仪表、压缩机、低温储罐。

R410A / R407C / R404A / R507A

HFC混配
原材料R32、R125、R134a、R143a等单质HFC。
混配逻辑R410A=R32/R125；R407C=R32/R125/R134a；R404A=R125/R143a/R134a；R507A=R125/R143a。
流程单质检测 → 干燥 → 按配比计量 → 混合均质 → 复检 → 充装。
关键设备电子秤/质量流量计、混配釜、循环泵、分子筛干燥器、GC检测、钢瓶/ISO tank充装。

HFO-1234yf

汽车空调替代
原材料C3氯代中间体、AHF；部分路线可涉及HCC-240、四氯丙烯、HCFO-1233xf等中间体。
典型路径C3氯代中间体 → 氟化/异构化 → HCFO-1233xf等 → 进一步转化/脱卤化氢 → HFO-1234yf。
产品去向汽车空调低GWP替代核心产品，也用于低GWP混配。
关键设备多级反应器、异构化单元、酸气处理、精馏提纯、微量杂质控制、客户认证检测。

HFO-1234ze / HCFO-1233zd

冷水机/发泡剂
原材料HCC-240系列、HFC-245fa、HCFC-244fa等C3含氯/含氟中间体。
典型路径C3中间体氟化/脱卤化氢/异构化 → 1234ze或1233zd → 精馏分离异构体。
产品去向离心冷水机、热泵、发泡剂、溶剂；1233zd常见于低压冷水机和发泡替代。
关键设备氟化反应器、异构体分离塔、尾气吸收、中间体回收、低水分包装系统。

R513A / R454B / R448A / R449A

低GWP混配
原材料HFC单质 + HFO单质，如R134a、R32、R125、R1234yf、R1234ze等。
路线不新增化学反应，核心在单质供应、混配精度、杂质/水分控制和应用认证。
产品去向替代R134a、R410A、R404A/R507A等高GWP产品。
关键设备混配釜、低温液体输送、称重计量、在线分析、气瓶阀门兼容性检测。

R290 / R600a

烃类天然工质
原材料丙烷、异丁烷，来自炼厂气、天然气分离或石化副产。
流程烃源分离 → 深度脱硫/脱水/除杂 → 精馏提纯 → 制冷剂级包装。
产品去向冰箱、冷柜、热泵、小型空调探索；优势是低GWP，约束是A3可燃。
关键设备精馏塔、吸附脱硫/干燥、低温储罐、防爆泵阀、泄漏检测和充装系统。

R717 / R744

氨 / 二氧化碳
原材料R717来自合成氨体系；R744来自工业CO2净化提纯。
流程合成/回收气源 → 脱水除杂 → 压缩液化 → 制冷剂级储运。
产品去向工业制冷、冷库、食品加工、商超跨临界CO2系统、热泵。
关键设备压缩机、冷凝器、净化塔、储罐；CO2系统还需要高压管阀和专用压缩机。

数据中心液冷介质

算力温控
介质类型水/乙二醇、丙二醇、去离子水、合成烃、硅油/酯类、氟化液等。
系统路径冷站制冷剂侧 → 冷冻水/一次侧 → CDU换热 → 二次侧冷板/浸没槽 → 服务器芯片。
与制冷剂关系高密度AI机柜的“服务器侧”用冷却液；园区冷站仍可能使用R134a、HFO、低GWP混配或自然冷却。
关键设备冷水机组、冷却塔、板式换热器、CDU、泵、快接头、冷板、浸没槽、过滤/监测系统。

产业判断：哪些环节最值得跟踪

1. 传统HFC看“配额 + 价差”

R32、R125、R134a、R143a已经从产能周期转向配额周期。量受限时，利润弹性来自制冷剂价格与萤石/AHF/氯代烃成本之间的价差。

  • 核心：配额规模、产品结构、出口/内销比例。
  • 风险：需求淡季、替代品加速、政策削减节奏。

2. HFO看“技术 + 客户认证”

HFO不是简单扩产就能卖高价。汽车空调、冷水机等客户认证周期长，对杂质、稳定性、可靠性要求高，技术路线和专利壁垒比HFC更强。

  • 核心：R1234yf、R1234ze、R1233zd。
  • 风险：专利、成本、国外龙头价格策略。

3. 算力制冷要分清“冷媒”和“冷却液”

数据中心冷站仍可能带动冷水机制冷剂，但AI机柜侧快速增长的是液冷介质、CDU、冷板、泵阀、快接头，不是R32/R125这类传统家空冷媒。

  • 核心：液冷渗透率、单机柜功率、PUE要求。
  • 风险：技术路线在冷板、浸没、风液混合之间切换。
