# Reports

这是一个 GitHub Pages 静态报告仓库，按主题分开存放产业链研究页面。

## 目录

- `index.html`：制冷剂产业链长图首页
- `assets/refrigerant_industry_chain_map.pdf`：制冷剂产业链 PDF 版本
- `molybdenum-industry-chain/index.html`：钼产业链报告，保留在独立旧目录
- `reports/index.html`：报告目录页
- `reports/memory_chip_industry_chain/index.html`：存储芯片产业链报告

## 发布

仓库使用 GitHub Pages 静态部署。当前 workflow 监听 `gh-pages` 分支推送，合并或同步到该分支后会自动部署。
